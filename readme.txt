Frontend Setup (Angular):

Install Node.js 20.10.0 (older versions may also work).
Download from: https://nodejs.org/

Install Angular CLI:
npm install -g @angular/cli

Navigate to the frontend project folder and install dependencies:

npm install

Start the Angular project:

ng s -o

This will open the project in the browser.


Backend Setup (Flask + RAG Model):

Open VS Code and load the backend folder.

Ensure you have Python installed.

Open the rag.ipynb in VS Code.

Run all cells by clicking "Run All" in the Jupyter notebook interface.

The Flask server should now be running.

✅ Now frontend and backend are ready! 🎉
